# Pill: что хотим (согласовано 2026-11-11, обновлено 2026-11-12)

## Партия 1: главное
- [x] **Прятаться в полноэкранных** играх и видео (`ABN_FULLSCREENAPP`), возвращаться после выхода.
- [x] **Окно громкости** вместо системного: полоска в пилюле при смене громкости (`IAudioEndpointVolumeCallback`).
- [x] **Яркость везде**: на ноуте встроенный экран (WMI), на ПК внешний монитор по DDC/CI. Ползунок в «Управлении», окно в пилюле при смене. Проверено только на ПК; на ноутбуке (WMI, OSD от клавиш) не проверено.
- [x] **Зарядка и батарея** (только где есть батарея, на ПК выключено): «⚡ 64%» при подключении, предупреждения при 20% и 10%.
- [x] **Музыка в свёрнутой пилюле**: значок-эквалайзер (вместо обложки) и полоска прогресса. В раскрытой: время трека и перемотка кликом.
- [x] **Микрофон и камера заняты**: точка в пилюле (реестр `CapabilityAccessManager`, по событию).
- [x] **Кнопка скриншота области** (`ms-screenclip:`).

## Партия 2 (согласовано 2026-11-12, идеи из Lumen, HeyyCzer/windows-dynamic-island, oyenza-studio; код свой)
- [x] **Визуализатор музыки**: 4 столбика в свёрнутой пилюле и 24 полоски во вкладке «Музыка». WASAPI loopback, своя FFT, работает только пока играет и пилюлю видно. Осознанное исключение из «0% CPU»: ~0,3% ядра (замерено).
- [x] **Монитор системы**: CPU, RAM, GPU, сеть, диски, топ процессов. Читаем раз в секунду и только пока открыта вкладка. Проверено на ПК; ноутбук и несколько видеокарт не проверены.
- [x] **Предупреждение о нагрузке**: CPU или память в потолке 30 с, с именем процесса. Проверено только тестами, вживую 30 с при 90% не гоняли.
- [ ] **Скриншот открывает чёлку** с картинкой: скопировать, открыть, перетащить.
- [ ] **Заряд Bluetooth-наушников** при подключении (если получится просто).
- [ ] **Локальный API для скриптов** (`events.rs`, `127.0.0.1`): события и статусы задач в чёлке.
- [ ] **Ctrl+F по экрану**: распознавание текста встроенным OCR Windows (`Windows.Media.Ocr`), подсветка совпадений. Только по нажатию.

## Потенциальные фичи (идеи 2026-11-12, не согласованы, только запомнить)
- [ ] **Агенты в чёлке**: статус ИИ-агентов (Claude Code в VS Code и других местах): работает / ждёт ответа / закончил / нужно разрешение. Основа уже есть в пункте «Локальный API для скриптов» (`events.rs`): агенты и хуки шлют события на `127.0.0.1`, чёлка показывает бейдж и короткую строку.
- [ ] **Уведомления вместо стандартных (Telegram и др.)**: показывать их в чёлке, а не тостами Windows. Варианты источника: `UserNotificationListener` (читает тосты любых приложений, нужно разрешение) или прямой Bot API Telegram. Решить при старте. Заменяет пункт «Уведомления Windows» из «Отказались».
- [ ] **Организация вкладок**: сейчас вкладки (Музыка, Буфер, Команды, Управление, Система) идут плоским рядом, а функций станет больше (агенты, уведомления). Нужна удобная структура: например, вкладки вложены друг в друга или сгруппированы («Управление» и «Система» вместе, внутри подвкладки), чтобы всё было под рукой и не разрасталось в длинный ряд. Конкретную схему ещё придумать, сначала набросать варианты.
