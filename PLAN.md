# План: новый дизайн Pill по кускам

Составлен 2026-11-14. Макеты и обоснования: https://claude.ai/artifact/9pAtQ8kyWNqDz1BumW9gKk (страница приватная, открывается из аккаунта владельца).
Перед работой читать [ARCHITECTURE.md](ARCHITECTURE.md): бюджет лёгкости, 4 потока, правило `st()`.

## Как работать по плану

- Один кусок = одна сессия = один коммит. Куски внутри этапа идут по порядку, этапы 3–5 можно менять местами.
- После каждого куска: `cargo build --release`, `cargo test --release`, замер (CPU в простое за 60 с, WS, приватная память, размер exe), потом агент `docs-writer`.
- Размер куска: **мелкий** (до ~150 строк), **средний** (150–400), **крупный** (больше 400 или есть неясность, сначала проба).
- Потолки из ARCHITECTURE: WS ≤ 30 МБ (сейчас 26,5), приватная ≤ 10 МБ (4,8), exe ≤ 1,5 МБ (771 КБ), потоков ровно 4.

## Решения, принятые 2026-11-14

- «Буфер» и «Команды» больше не вкладки, а режимы одной строки поиска (Alt+Space, Ctrl+Alt+V, лупа в шапке).
- Вкладки: Музыка, Полка, Система, События. Пока полки нет (до этапа 8), вкладок три.
- Режимы ПК: тишина от Pill и закрытие программ по списку. Включение вручную, плюс подсказка в пилюле. План питания и запуск программ не трогаем.
- Передача файлов: сначала с ПК на телефон по коду на экране. Приём с телефона, портал на ноутбук и общий буфер отложены.
- Маскоты рисуются кодом, без картинок и без своего таймера (кадр глаз с секундного тика).

- Режимы: Обычный, Монтаж, Рендер, Игра. Переключатель в «Управлении», команда в поиске, подпись в пилюле, пока режим не обычный.
- Тишина: не показывать карточки чужих уведомлений и не раскрываться самому. Запросы разрешений остаются.
- Закрытие программ по списку из настроек: вежливо, `WM_CLOSE` окнам, не снятие процесса. Программа, спросившая «сохранить?», остаётся.
- Подсказка «Включить „Монтаж“?»: по событию смены активного окна, один раз за запуск программы. Без слежения за процессами.

## Партия 4: пожелания от 14.11 (вечер), ничего из этого ещё не начато

Порядок рекомендованный. Сначала быстрые правки, потом макеты (редизайн затрагивает все вкладки, поэтому его надо утвердить до полки, режимов и окна настроек), потом реализация.

### Этап 11. Быстрые правки (сделано 14.11)
Сделано: Ctrl+Alt+H прячет пилюлю целиком и возвращает (её также возвращают хоткей поиска и просьба агента); маскот агента стоит левее обложки трека; ползунки громкости и яркости тащатся мышью (захват мыши на время перетаскивания). Проверено: скрытие и возврат по снимкам экрана, порядок значков тестом. Перетаскивание руками не проверено. Автовозврата по времени нет. Исходное описание:
- **Спрятать пилюлю сочетанием клавиш**, чтобы нажать то, что под ней (вкладку браузера). Повторное нажатие возвращает. Сочетание выбрать (предложение: Ctrl+Alt+H); продумать автовозврат через N секунд и возврат по событию (просьба агента).
- **Агент левее музыки** в свёрнутой чёлке: порядок значков в `pill::assemble` (сейчас обложка идёт раньше маскота).
- **Ползунки громкости и яркости перетаскиванием**: зажал и тащишь (`SetCapture`, `WM_MOUSEMOVE` с зажатой кнопкой, `WM_LBUTTONUP`), а не только клик. Яркость по DDC медленная: слать в воркер не чаще, чем он успевает, последнее значение выигрывает (так уже устроен `Job::SetBrightness`).

### Этап 12. Редизайн 2.0: сначала макеты
Новая страница макетов (как первая), утверждается пользователем до кода.
- **Все вкладки в стиле Apple**: минимализм, больше воздуха, меньше рамок и подписей, аккуратная типографика. Пересмотреть шапку, карточки, плитки, списки.
- **«Музыка»**: убрать пустоту под громкостью; сразу заложить место под текст песни (этап 10), чтобы не перекраивать второй раз.
- **Агенты в «Событиях»**: сейчас красиво, но бесполезно. Придумать, что там можно делать: ответить на просьбу прямо из карточки, перейти в окно агента, увидеть ход работы (шаги, план), историю за день, остановить агента. Что из этого реально, зависит от хуков: проверить по документации.
- **Маскоты**: несколько агентов по очереди сменяют друг друга в чёлке, больше состояний и мелких анимаций (моргание, подпрыгивание при событии, сон у давно молчащего). Бюджет прежний: без своего таймера в простое, кадры только пока есть что показывать.

### Этап 13. Реализация редизайна
По вкладке за сессию, каждая сверяется с макетом по снимку экрана (`/open?tab=...`).

### Этап 14. Плавные анимации
Раскрытие, сворачивание, карточка, смена ширины свёрнутой чёлки (сейчас мгновенная), появление содержимого. Сейчас 200 мс и ~13 кадров с полной перерисовкой: подобрать кривую и длительность, привязать кадры к обновлению экрана, не рисовать текст заново на каждом кадре, если можно растянуть готовый кадр. Только во время перехода, в простое таймеров нет.

### Этап 15. Окно настроек
Отдельное окно (не вкладка) вместо подменю в трее: размеры и задержки, звуки и тихие часы, клавиши (спрятать пилюлю, ответы агенту), автораскрытие для просьб и вопросов, режим «просто точка», списки программ для режимов ПК и исключений, установка хуков Claude Code (кусок 6.4). Файл `settings.txt` остаётся источником правды. Нужно решить: рисовать своим `Painter` в том же стиле или обычными элементами Windows.

### Этап 16. Уведомления пилюли вместо системных
Сейчас сообщение показывается дважды: карточкой Pill и баннером Windows. Сначала проба: какой способ прячет баннеры, но оставляет уведомления в центре уведомлений, откуда Pill их читает (режим «Не беспокоить», настройка баннеров по программам в реестре). Если способ есть, включать его из настроек Pill и возвращать как было при выходе. Если нет, остаётся ручное выключение баннеров в Параметрах.
